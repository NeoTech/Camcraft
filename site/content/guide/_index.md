This guide follows a job from start to finish: install the app, import a
model, set up stock, work offset and tools, add operations, check them, and
post the program. The last page explains what to do when CamCraft refuses a
post.

Multi-axis work (indexed 3+1 and 3+2, continuous 4-axis, simultaneous 5-axis,
TCP and the checks) has its own section:
[4-axis and 5-axis machining](@/guide/multi-axis/_index.md).
