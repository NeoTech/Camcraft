Open CamCraft in the browser

{% if version %}The browser build is CamCraft {{ version }}, built from the same release tag as this site.{% else %}A released site carries the browser build of its release; this local preview does not.{% endif %} It runs in a current browser on WebGL2, with nothing to install. It is an early build: there is no file picker yet (models, projects and programs cannot be opened or saved), simulation playback does not work yet (it runs on a thread, and the browser gives the shell none), it does not use WebGPU, and views that need desktop GPU features say so instead of drawing. Use the desktop downloads for real work (#31 tracks what is still owed).
