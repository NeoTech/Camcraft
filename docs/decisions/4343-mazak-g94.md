## #4343 - The Mazak post states G94

**What was decided.** The Mazak section preamble writes `G94` with its other
modal words: `G17 G90 G94 <wcs> G40 G49 G80`. Each section restates it, so
the first F word of every section comes after a `G94`.

**Why.** Every F word that the post writes is a feed per minute. A control
can be in `G95` (feed per revolution) from its power-on setting, an earlier
program or MDI. The section preamble already restates the plane, the
distance mode, the work offset and the cycle state for the same reason. The
Haas post writes the same block, and #4150 (PR #4169) put `G94` in the
Sinumerik 840D preamble.

**Considered and dropped.** `G94` once at program start, in `onOpen`. A
program that an operator starts at a later section (a restart at a block
number) would then miss it.

**Side effect.** With Explain G-code on, the preamble's comment is cut at the
post's 60-character `commentMax`. It now reads "XY PLANE, ABSOLUTE
POSITIONS, FEED PER MINUTE" and no longer names the work offset. The Haas
explain golden ends the same way for the same block.

**Cost to change later.** One word in one block and the Mazak goldens.
